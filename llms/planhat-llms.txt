# Planhat

> Planhat is a Customer Platform for B2B SaaS — unifying customer success, product usage, revenue and post-sales operations. It exposes a REST API (api.planhat.com), a separate analytics/tracking endpoint (analytics.planhat.com), bulk upsert, an OAuth 2.0 authorization server, and an official remote MCP server (api.planhat.com/v1/mcp) for AI agents. This llms.txt was generated by the API Evangelist enrichment pipeline from Planhat's public developer surface.

## APIs

- [Planhat REST API](https://www.planhat.com/developers/api/introduction): Read/write companies, endusers, licenses, conversations, notes, tasks, opportunities, deals, sales, invoices, assets, issues, tickets, projects, NPS, churn, metrics and custom models. Base URL https://api.planhat.com. Bearer (Private App) token; limit/offset pagination; PUT bulk upsert.
- [Planhat Analytics API](https://www.planhat.com/developers/api/user-activities): Push user activities and usage metrics. Base URL https://analytics.planhat.com/analytics/{tenantUUID}.
